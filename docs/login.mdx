The landing page identifies the Federation Registry tenant and provides the
**Login** action. Authentication is handled by the tenant's authentication
proxy; Federation Registry does not ask you to create a separate password.

#### Federation Registry landing page and Login action

![Federation Registry landing page and Login action](/img/screenshots/landing_page.png)

To sign in:

1. Select **Login** on the landing page.
2. Select your identity provider from the list presented by the authentication
   proxy.
3. Authenticate with that provider.
4. Review and accept the consent request, if one is shown.
5. You are redirected to Federation Registry. Your user menu is displayed in
   the upper-right corner.

Your access is determined from information returned by the authentication
proxy. Consequently, the services and actions visible to you can differ from
those available to another user. See [Users and Roles](users) for details.
